# Referências

- `fotos/`: fotos reais dos espaços, sem pessoas.
- `capturas/`: capturas reais do servidor.
- `trilhas/`: modelos das zonas renderizados fora do jogo, sozinhos e ao lado da foto de referência. Não são capturas do servidor.
- `atividades/`: ilustrações das 13 missões. Não são registros de sessões.
- `previas/`: imagens renderizadas fora do jogo, para conferir os modelos. Não são capturas do servidor.
