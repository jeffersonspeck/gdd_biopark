# Avaliação e evidências

## Rubrica por missão

| Nota | Critério |
|---|---|
| 3 – Domina | Concluiu sozinho e explica o conceito com as próprias palavras |
| 2 – Consegue | Concluiu e explica parcialmente |
| 1 – Em desenvolvimento | Concluiu com bastante ajuda |
| 0 – Não concluiu | Não concluiu ou não participou |

## Como calcular os indicadores

| Indicador | Cálculo | Fonte |
|---|---|---|
| Conclusão por estudante | Missões concluídas ÷ 13 missões disponíveis | Progresso no Quests e rubrica |
| Estudantes que concluem as trilhas | Estudantes com 70% ou mais | Planilha de avaliação |
| Sessões realizadas | Sessões com lista de presença | Lista de presença |
| Trilhas liberadas | Zonas abertas e testadas | Checklist de instalação |

## Evidências a guardar

| Evidência | Como obter | Onde guardar |
|---|---|---|
| Lista de presença | `dados/modelo_presenca.csv` | Pasta restrita |
| Avaliação por rubrica | `dados/modelo_avaliacao.csv` | Pasta restrita |
| Logs do servidor | Painel da hospedagem, pasta `logs/` | Pasta restrita |
| Progresso das missões | `plugins/Quests/data/` | Pasta restrita |
| Capturas de tela | Tecla F2 no jogo | `referencias/capturas/`, se não houver dados pessoais |
| GDD versionado | Histórico deste repositório | Git |

**Registre só o que aconteceu.** Logs, listas e números devem vir das sessões reais, sem edição.

## Privacidade (LGPD)

- Colete o mínimo necessário e obtenha a autorização dos responsáveis pelos menores.
- Use código ou apelido, não nome completo, em relatórios públicos.
- Não publique fotos de menores.
- Não coloque listas, logs com nomes de jogadores ou dados do Quests no repositório. O `.gitignore` bloqueia as pastas mais comuns.
