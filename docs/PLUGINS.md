# Plugins e dependências

Preencha a coluna "Versão em uso" com o que está instalado no servidor. Assim, qualquer pessoa consegue reproduzir o ambiente.

| Item | Função no projeto | Obrigatório | Versão em uso | Onde baixar |
|---|---|---|---|---|
| Paper | Software do servidor | Sim | a preencher | https://papermc.io/downloads/paper |
| WorldEdit | Colar e editar as construções | Sim | a preencher | https://enginehub.org/worldedit |
| WorldGuard | Proteger as áreas do mapa | Sim | a preencher | https://enginehub.org/worldguard |
| Citizens | Criar os NPCs | Sim | a preencher | https://citizensnpcs.co |
| Quests | Missões e progresso dos alunos | Sim | a preencher | https://www.spigotmc.org/resources/quests.3711/ |
| Mod de texturas | Visual do mundo e dos objetos | Não | a preencher nome e versão | a preencher |
| ImageFrame | Letreiro e imagens em mapas | Só para o letreiro | a preencher | https://modrinth.com/plugin/imageframe |

## Ferramentas de desenvolvimento

| Ferramenta | Uso |
|---|---|
| Blockbench | Modelos 3D de móveis e objetos |
| Python 3 | Scripts de `tools/` |
| Git | Versionamento do GDD e dos arquivos |

## Observações

- Baixe sempre das páginas oficiais.
- WorldGuard depende do WorldEdit.
- Quests depende do Citizens para usar NPCs nas missões.
- Antes de atualizar o jogo, confirme se todos os plugins já suportam a nova versão.
